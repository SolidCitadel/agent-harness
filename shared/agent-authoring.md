# Agent 작성 규율

## 역할과 호출 조건

- 작업에 필요한 맥락·책임·권한을 분리해 맡기는 이점이 위임·조정 비용을 정당화할 때 agent를 둔다.
- description은 맡을 작업과 위임할 조건을 명시한다. 호출 전에 충족해야 할 입력 요건은 호출자가 확인할 수 있도록 연결한다.

## 명세와 호출 경로

- 본문은 맡은 작업의 목적·범위·권한과 필요한 수행 기준을 규정한다. 완료 시 반환할 결과와, 작업을 중단하거나 호출자에게 판단을 돌려줄 조건을 명시한다.
- 호출자가 준비·결정할 사항은 관련 skill·workflow 등 호출 전에 읽히는 위치에 둔다. 입력·출력과 책임 경계는 정본을 정하고 양쪽에서 필요한 내용을 참조하도록 연결한다.
- 수행에 필요한 정보와 독립성을 위해 전달을 제한할 정보를 정한다. 호출자가 그 조건에 맞는 맥락 전달 방식을 선택하도록 호출 경로에 명시한다.
- 호출자가 반환 결과를 작업 목적과 완료 기준에 대조해 다음 행동을 결정하도록 규정한다. 후속 작업을 위임할 때는 남은 문제와 추가로 필요한 결과를 구체화하도록 한다.

## 검증

- 맡은 작업과 입력 부족·범위 초과 상황을 대조해 수행·반환·중단 기준을 검토한다. 실제 실행에서는 역할·권한의 준수와 반환 결과의 적합성을 확인하며, 사례 검토에서 예상한 동작과 구분해 기록한다.
