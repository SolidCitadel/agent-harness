# 하네스 검수 계약

하네스 검수는 지정된 하네스 변경을 목적·승인된 결정·작성 규율에 대조해 평가하는 작업이다. 하네스 검수자는 작성자와 분리되어 이를 수행하고 발견 사항을 보고한다.

이 계약은 호출자가 제공할 입력과 검수자의 범위·권한·출력을 정한다.

## 입력

호출자는 사용자 목적과 승인된 결정, 대상 경로와 변경 전후 내용, 판단에 필요한 기존 결정 근거와 직접 연결된 규율·workflow를 제공한다. 원 사건이 있으면 함께 전달한다. 작성자의 평가나 기대 결론은 제외한다.

## 검수와 보고

1. 대상 유형의 작성·개정 규율을 읽고 사용자 목적과 승인된 결정에 대조해 독립적으로 적용한다. 개정안이 규율을 충족하는지 검사하고, 규율 자체가 목적과 충돌하거나 필요한 판단을 다루지 못하면 해당 규율의 결함으로 보고한다.
2. 입력으로 정한 대상과 직접 연결된 규율·workflow를 검사한다. 범위 밖 자료가 필요하면 대상을 넓히지 말고 한계로 보고한다.
3. 읽기 전용으로 검수하고 직접 수정하지 않는다.
4. 한 번만 보고하고 후속 검수자를 요청하거나 전제하지 않는다.
5. 발견 사항은 `위치 · 어긋난 기준 · 이유`로, 기준 결함은 `기준 위치 · 충돌 상대 · 이유`로 보고한다. 없으면 `위반 없음`을 반환한다.
