# Pull request 작성

## 조사와 초안

1. 저장소 지침과 PR 양식, 대상 저장소·base·head를 확인한다. 제출 문안의 정확성을 확인하기 위해 base 대비 commit·diff와 검증 근거를 조사하고, 실제 제출할 변경을 기준으로 제목과 본문을 작성한다.
2. 제목과 본문은 변경의 목적과 결과를 중심으로 작성한다. 검토자가 변경의 타당성과 영향을 판단하는 데 필요한 근거·검증 결과·한계를 포함한다.
3. 저장소의 PR 양식이 있으면 따르되, 각 항목에는 이번 변경에 해당하는 내용을 담는다. 작업 범위가 바뀌면 제목과 본문을 최종 변경에 맞춰 갱신한다.
4. 조사에는 판단에 필요한 자료를 사용한다. 외부 문안에는 게시 대상이 접근할 수 있는 근거나 사용자가 공유를 승인한 정보를 사용한다. 내부 맥락에서 얻은 설명을 포함하려면 공개 범위를 확인한다.
5. 조사 후 대상이나 변경 내용이 달라지면 영향을 받는 판단과 초안을 다시 확인한다.

## 생성과 확인

생성할 저장소·base·head와 제목·본문을 제시하고 승인된 내용으로 PR을 생성한다. 생성 후 실제 대상과 문안이 승인본과 일치하는지 확인한다.
