# 브레인스토밍

## 작업 절차
1. 문제 공간이 정의되지 않았다면 먼저 `grill-me`로 목표와 제약을 합의한다.
2. 서로 다른 접근을 범주별로 넓게 탐색한다.
3. 중복되거나 명백히 부적합한 안은 제거한다.
4. 대표안과 의미 있는 변형을 근거·장단점·권고 순서와 함께 제시한다.
5. 방향이 정해지면 `grill-me`의 설계 계약으로 수렴한다.
