# 브레인스토밍

## 작업 절차
1. 가능한 모든 방법을 탐색한다. 현실성이나 적절성은 고려하지 않고, 최대한 넓게 탐색하는것에 집중한다.
2. 각 아이디어별로 적절성을 판단해 평가한다.
3. 무의미한 수준의 아이디어가 아닌 이상 사용자에게 전부 제시한다. 단 순서는 스스로 적절하다고 생각하는 순위를 지킨다. 각각의 장단점 및 설명을 첨부한다.
4. 사용자와 의사소통하며 합의점을 찾는다.
