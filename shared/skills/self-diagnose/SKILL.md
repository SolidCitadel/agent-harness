# 수행 진단과 교정

## 기대와 실제 수행 대조

1. 사용자 발화와 당시 맥락에서 기대한 결과·수행 방식을 확인한다.
2. 실제 응답·행동·산출물과 대조해 어긋난 지점을 구체화한다.
3. 당시 이용할 수 있었던 정보·지침과 이후 새로 확인한 기대를 구분한다.

## 원인 추적

어긋남이 발생한 과정을 따라 어떤 정보·해석·판단·행동 또는 실행 조건이 결과에 영향을 주었는지 확인한다. 원인 후보를 당시 근거와 대조하고, 그 원인을 교정하면 어긋남을 줄일 수 있는지 검토한다.

여러 원인이 함께 작용할 수 있으며, 확인하지 못한 부분은 가설로 남긴다. 원인은 교정할 지점이 드러나도록 설명한다.

## 교정안 구성

현재 작업을 보정하는 것과 함께 같은 어긋남을 줄일 개선안을 탐색한다. 각 안이 원인에 작용하는 방식과 예상 효과·부작용을 대조하고, 불확실한 부분은 가설과 확인 방법을 명시해 제안한다.

기대와 실제 수행의 차이, 원인과 가설, 현재 작업의 보정안과 재발 방지 개선안, 확인 방법을 사용자가 판단할 수 있을 만큼 구체적으로 제시한다. 해결하지 못한 원인과 남은 위험도 밝힌다.

## 실행과 확인

이미 승인된 작업 안의 보정은 수행하고, 승인된 방향이나 지침을 바꾸는 개선안은 사용자와 합의한 뒤 실행한다.

선택한 교정에 맞는 절차로 실행하고, 기대한 변화와 남은 문제를 확인한다. 하네스 개정은 해당 플랫폼의 공통 하네스 작성 규율에 따라 검수하고 판단 근거를 기록한다.
