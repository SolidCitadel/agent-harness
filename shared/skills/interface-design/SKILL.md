# 인터페이스 설계

## 제품 목적과 사용 흐름

1. 핵심 사용자·작업·사용 조건과 제품의 품질 우선순위를 확인한다. 디자인 선택은 그 목적과 우선순위에 대조해 판단한다.
2. 대표 유즈케이스를 시작부터 완료까지 따라가며 조작·화면 이동·입력·피드백·복구 과정을 검토한다. 불필요한 조작과 정보 탐색·기억 부담을 찾아 줄이되, 조작 수를 줄이는 선택이 화면 복잡성이나 오류 가능성을 높이는지도 비교한다.
3. 이미 합의한 기능·흐름과 새로 결정할 사항을 구분한다. 제품 동작이나 정보 구조를 바꿔야 하면 이유와 영향을 제시하고 사용자와 합의한다. 실행 방안의 공동 구체화가 필요하면 `grill-me`를 읽고 이어간다.

## 시각 규칙

1. 기존 제품의 디자인 규칙과 대응 화면을 확인하고, 이번 작업에 유지할 기준과 보완할 부분을 구분한다.
2. 시안이나 구현을 만들기 전에 필요한 타이포그래피·색·간격·배치·상태 표현의 규칙과 적용 조건을 정의한다. 개별 값은 이 규칙에서 도출하고, 규칙 사이의 일관성을 확인한다.
3. 새로 정하거나 변경할 규칙은 제품 목적·사용 조건·품질 우선순위에 근거해 제안하고 사용자와 확정한다. 기존 기준으로 판단할 수 있는 세부 선택은 그 기준에 따라 진행한다.

## 시안과 구현

1. 사용 흐름이나 시각적 결과에 대한 선택·확인이 필요하면, 이를 판단할 수 있는 시안을 만든다. 실제 사용을 대표하는 콘텐츠로 합의한 흐름과 시각 규칙을 표현한다.
2. 시안을 만든 경우 핵심 작업의 수행 과정과 정보 위계·가독성·조작 편의성을 사용자와 검토하고, 구현할 방안을 확정한다.
3. 확정한 흐름과 시각 규칙에 따라 구현한다. 제작 중 변경이 필요하면 기존 기준으로 해결할 세부 조정과 사용자 합의가 필요한 변경을 구분하고, 변경한 규칙을 영향을 받는 부분에 함께 적용한다.

## 사용성과 시각 검증

1. 실제 렌더링과 상호작용으로 핵심 작업을 수행하며, 의도한 흐름으로 완료할 수 있는지와 불필요한 조작·탐색 부담이 있는지 확인한다.
2. 실제 사용에서 예상되는 콘텐츠 길이·양·결측, 화면 크기와 상태 변화를 대입한다. 정보의 가독성, 요소의 겹침·잘림·넘침, 조작 대상의 접근·식별 가능성과 동작 피드백을 확인한다.
3. 결과를 확정한 흐름·시각 규칙·품질 우선순위에 대조한다. 발견한 결함을 수정하고 영향을 받는 조건에서 다시 확인한다. 합의한 기준을 변경해야 하면 이유와 영향을 제시해 사용자와 결정한다.
4. 실제 확인한 사용 조건과 결과, 확인하지 못한 범위와 남은 문제를 구분해 보고한다.
