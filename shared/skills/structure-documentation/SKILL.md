# 문서 구조화

## 조사와 범위

1. 제품·운영에서 독자가 수행할 작업과 필요한 정보를 도출하고, 기존 문서·정본과 대조한다. 예상되는 문서 수요와 이미 확인된 기록 필요를 구분한다.
2. 기존 문서의 책임과 반영 방식으로 내용을 수용할 수 있는지 확인한다. 새로 결정하거나 변경해야 하는 정보 배치·정본·참조·갱신 관계까지 검토 범위를 정한다.
3. 미정인 제품·운영 사항은 확정된 내용과 구분한다. 문서의 책임·배치나 작성 내용을 결정하는 데 필요한 사항은 사용자와 합의하고, 공동 구체화가 필요하면 `grill-me`를 읽고 이어간다.

## 배치와 갱신 설계

1. 검토 범위에서 각 문서·절이 맡을 독자와 작업, 소유할 정보와 경계, 진입·참조 경로, 갱신 계기와 담당 주체·절차를 정한다.
2. 정보가 현재 상태·기준을 설명하는지, 사건·결정 이력을 남기는지 구분하고 그에 맞는 갱신 방식을 정한다. 현재 정보는 기존 내용을 갱신하고, 이력은 사건을 누적한다.
3. 정본은 원천 정보와 갱신 경로를 기준으로 정한다. 변경을 따라 갱신할 수 없는 복사본은 정본으로 삼지 않고, 원천 참조나 자동 생성으로 연결한다.
4. 기존 배치를 바꾸면 이동·통합·폐기할 내용과 필요한 맥락의 보존 방법을 함께 정한다. 제안한 배치와 변경 영향을 사용자와 합의한다.

## 작성과 검증

1. 합의한 문서 체계와 배치에 따라 작성·이동·통합하고 참조를 갱신한다.
2. 내용이 실제 사실과 문서의 책임·범위에 맞는지 대조하고, 독자의 작업에서 필요한 정보를 찾아 사용할 수 있는지 확인한다.
3. 변경된 정보의 정본과 관련 문서를 함께 갱신하고, 대체된 내용이 현재 정보로 남아 있지 않은지 확인한다.
4. 링크·형식·생성물 일치처럼 기계적으로 판별할 항목을 검사한다. 의미와 사용 적합성은 내용 및 사용 경로를 대조해 확인한다.
