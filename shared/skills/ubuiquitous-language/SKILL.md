# Ubiqutous Language
- 공통 단어집(사전)을 만들어서 사용자와 합의하고, AI의 사고방식을 덜 장황하고 일관되도록 정의한다.

## 저장 위치
- 규칙 수준에 따라 적절한 위치의 CLAUDE.md, rules 등에 정의하여 지속적으로 참조 가능하도록 한다.

## 표현 방안
- 키워드: 정의 형태로 구성된다.
- 유사 개념끼리는 별도 섹션으로 묶고, 차이점까지 정의한다.

### 예시
```
### 테스트 / 평가 / 품질
- `Benchmark`: 직접 엄선한 입력 케이스와 정답 조건을 통해 엣지케이스 해결 능력을 평가하고 비교하기 위한 테스트
- `Test`: 시스템이 정상적으로 동작하는지 결정론적으로 평가하는 스크립트
- `Eval`: 파인튜닝 등 머신러닝을 위해 전체 데이터셋에서 split 한 eval split을 기준으로 학습 성과 측정
- 차이점: Test는 품질 평가나 비교가 목적이 아니다. 전체 데이터셋의 랜덤한 일부를 사용하는것은 eval, 그 중에 엄선한 챌린징 케이스가 Benchmark이다.
```
