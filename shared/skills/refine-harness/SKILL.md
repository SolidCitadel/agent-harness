# 하네스 정제

Codex는 `~/.codex/harness-authoring.md`와 `~/.codex/harness-components.md`, Claude Code는 `~/.claude/harness-authoring.md`와 `~/.claude/rules/harness-authoring.md`를 읽는다.

## 검토 범위

1. 사용자와 검토 묶음과 목적을 정한다. skill·전역 지침·섹션·workflow 등을 출발점으로, 함께 판단해야 하는 책임과 연결을 확인한다.
2. 유지할 요구와 재평가할 구현을 구분한다. 기존 요구를 변경해야 하면 근거와 영향을 합의한다.
3. 현재 판단이나 승인한 변경을 성립시키는 데 필요한 직접 의존성을 확인한다. 다른 책임이나 별도의 결정이 필요한 문제는 현재 묶음에 포함할지 후속 검토로 남길지 사용자와 정한다.

## 개별 판단과 구조 검토

1. 묶음 안의 각 의무·조건·주장을 심사한다. 원문의 기능, 유지·변경 후보, 근거와 사례·반례를 제시하고 판단이 연결되는 항목은 함께 대조한다.
2. 결과를 좌우하는 결정을 사용자와 순차적으로 합의한다.
3. 개별 판단을 모아 문서 내부 구조와 관련 구성물 사이의 책임·순서·중복·참조·배치를 재검토한다.
4. 구상한 변경안을 통합해 사용자가 유지할 요구와 대조할 수 있을 만큼 구체적으로 제시하고 검토받는다.

## 반영과 완료

승인한 변경을 정본과 필요한 파생물·연결에 반영한다. 공통 하네스 작성 규율에 따라 검수·검증하고 개정 근거를 기록한다.

검토 묶음의 각 판단 단위에 대한 처분과 이유, 유지할 요구의 충족 여부, 필요한 책임과 읽기 연결을 확인한다. 검수·검증 결과와 미확인 범위, 해결하지 않은 문제와 후속 검토 대상을 구분해 보고한다.
