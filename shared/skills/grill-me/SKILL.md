# 작업 구체화

사용자가 완성된 지침을 준비하지 않아도, 질문·조사·제안과 반복 검토를 통해 실행 가능한 방안을 함께 만든다. 결과의 품질과 사용자 의도의 일치를 우선한다.

## 조사와 질문

1. 요청과 실제 상태를 대조해 기대 결과, 제약, 이미 결정된 사항과 열린 선택을 파악한다. 조사로 확인할 사실은 직접 확인한다.
2. 방안을 실제로 실행한다고 가정하고, 실행자가 임의로 채워야 하는 중요한 결정을 찾는다. 의존성이 높은 결정부터 한 번에 1~3개씩 질문한다.
3. 추상적인 답은 구체적인 사례와 관찰 가능한 조건으로 좁힌다. 답변에서 새로 드러난 가정·누락·모순을 후속 질문으로 추적한다.
4. 선택의 근거와 영향을 설명하고 권고안을 제시한다. 사용자 답변이나 기존 관례가 목적·제약과 충돌하면 근거를 들어 재검토를 요청한다.

## 방안 구성과 반복 검토

1. 질문할 필요가 없는 세부사항은 AI가 구상한다.
2. 구상한 방안 전체를 사용자가 의도와 대조할 수 있을 만큼 구체적으로 제시한다. 사용자와 확정한 내용, AI의 제안, 미결정을 드러낸다. 글만으로 판단하기 어려운 부분은 시안·도식·예시·실험 등으로 구체화한다.
3. 방안의 시작부터 완료까지 실제 사용·실행 흐름을 따라가며 입력, 행위 주체, 권한, 상태 변화, 산출물과 성공 판정을 확인한다. 관련된 실패·취소·복구·경계 사례를 대입하고, 발견한 빈틈을 질문과 수정으로 해소한다. 변경이 영향을 주는 기존 결정도 다시 확인한다.
4. 조사·시안·실험으로 확인해야 하는 사항은 확인 방법과 결과에 따른 결정 방법을 정한다.

## 완료와 실행 인계

다음에 실행할 작업의 범위를 정하고, 그 작업에 대해 아래 조건을 충족한 방안을 사용자에게 제시해 승인받는다. 시안·조사·실험이 필요한 경우에는 그것을 다음 작업으로 삼고, 결과를 바탕으로 구체화를 이어간다.

- 기대 결과와 성공 여부를 판별할 기준이 구체적이다.
- 중요한 실행 결정을 임의로 보충하지 않아도 착수할 수 있다.
- 검토에서 발견한 모순과 중요한 누락이 해소되었다.
- 실행 중 확인할 사항은 확인 방법과 후속 결정 절차가 정해져 있다.
- 구상한 방안 전체를 사용자가 검토했고, 남은 세부 선택을 AI가 맡을 범위가 명확하다.
