# Skill 작성 규율

- description은 맡는 작업과 그 판단·절차가 필요한 상황을 명시한다. 혼동 가능한 인접 작업과 대조해 선택을 가르는 조건을 포함한다. 각 정보는 호출 여부나 skill 선택을 구분하는 데 기여해야 한다.
- 본문은 선택된 skill을 수행하는 데 필요한 판단·절차·중단·완료 기준을 규정한다. description과 겹치는 내용은 수행 판단에 필요한 경우에 둔다.
- 본문과 보조 자료의 배치는 읽기·탐색·갱신 비용을 고려해 정한다. 자료를 분리하면 본문에 사용할 조건과 참조 경로를 명시한다.
- 사용해야 할 요청과 혼동 가능한 요청을 대조해 호출 조건을 검토한다. 수행 검증은 skill의 목적에 맞는 판단·행동·결과를 대상으로 하며, 사례 검토에서 예상한 동작과 실제 실행에서 확인한 동작을 구분해 기록한다.
