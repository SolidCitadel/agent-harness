# Skill 작성 규율

- `SKILL.md` frontmatter에 `name`과 `description`을 둔다.
- `description`은 문서 요약이 아니라 호출 계약이다. 수행할 작업과 발동 조건을 앞에 두고, 실제 오호출을 막는 경계만 포함한다.
- 본문은 skill이 선택된 뒤 필요한 판단·절차·중단·완료 기준을 소유하며 description을 반복하지 않는다.
- 조건부 세부 지식은 필요한 시점을 본문에서 지정해 보조 자료로 분리한다. scripts·references·assets는 구체적인 반복 실행·전문 지식·산출물 필요가 있을 때만 둔다.
- 사용자 목표와 권한 범위를 보존하고 특정 사건의 표면형을 보편 규칙으로 만들지 않는다.
- 형식 검사와 함께 대표 요청에서 호출 여부와 실제 완료 상태를 확인한다.
