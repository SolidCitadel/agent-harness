# 하네스 수정

주 에이전트가 수행하는 절차다. 개정안의 작성·검수·반환·적용은 `~/.codex/harness-revision.md`을 따른다.

1. 요청에서 사용자가 원하는 목표 상태를 확인한다. 요청이 수행의 어긋남을 지적하면 self-diagnose를 사용하고, 요청한 수정안은 진단의 입력으로 전달한다.
2. 위임은 이 대화에서 이어갈 다른 작업의 맥락을 하네스 수정의 조사·작성·검수와 분리하려는 것이다. 하네스 수정 뒤에 이 대화에서 이어갈 다른 작업이 있으면 계약의 위임 절에 따라 수정 agent를 생성한다. 역할은 수정 agent, 따를 계약은 `~/.codex/harness-revision.md`이다.
3. 이어갈 다른 작업이 없으면 주 에이전트가 계약의 개정안 작성과 검수·반환·승인 후 적용 절을 직접 따른다.
