# 하네스 수정

주 에이전트가 수행하는 절차다. 개정안의 작성·검수·반환·적용은 `~/.codex/harness-revision.md`을 따른다.

1. 요청에서 사용자가 원하는 목표 상태를 확인한다. 요청이 수행의 어긋남을 지적하면 self-diagnose를 사용하고, 요청한 수정안은 진단의 입력으로 전달한다.
2. 주 에이전트가 직접 수행한다. 사용자가 위임을 지시·승인하거나, 주 에이전트가 맥락 한계 등으로 이 대화에서 이어갈 작업을 지키기 어렵다고 판단해 위임을 제안하고 승인받으면, 계약의 위임 절에 따라 수정 agent를 생성한다. 역할은 수정 agent, 따를 계약은 `~/.codex/harness-revision.md`이다.
