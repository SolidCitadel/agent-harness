# 맥락 정착

## 판단과 배치

1. 새 정보의 의미·적용 범위·지속성을 확인하고 기존 정본과 대조한다.
2. 사실·사용자 결정·AI의 추론을 구분한다. 기존 내용과 충돌하면 어느 쪽이 유효한지 확인한다.
3. 이후 사용할 주체와 시점을 기준으로 반영할 내용과 위치를 정한다. 기존 정본의 정보만으로 충분한지, 추가 기록이 어떤 효용을 갖는지 판단한다.
4. 문서별 책임이나 탐색 경로를 바꿔야 하면 `structure-documentation`으로 연결한다.

## 반영과 확인

반영할 내용·범위·위치와 기존 정보에 미치는 영향을 사용자가 검토할 수 있게 제시한다. 이미 승인된 내용과 위치는 그 승인을 활용하고, 새로 정해야 하는 결정은 합의한다.

승인된 범위에서 정본과 필요한 참조를 갱신한다. 의미가 충실히 반영됐으며 필요한 주체가 해당 정보에 도달할 수 있는지 확인한다.

하네스 개정 시 `~/.codex/harness-authoring.md`와 `~/.codex/harness-components.md`를 읽는다. 제품·운영 문서에 반영할 때는 해당 문서의 규율을 적용한다.
