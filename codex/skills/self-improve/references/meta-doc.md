# Codex 메타 문서 규율

## 소속

- 모든 작업에 걸리는 개인 기본값은 전역 `AGENTS.md`에 둔다.
- 특정 프로젝트나 하위 경로에만 걸리는 지침은 해당 경로의 `AGENTS.md`에 둔다.
- 명확한 사용자 목표를 수행하는 반복 절차는 skill에 둔다.
- 대화 생명주기나 도구 호출에서 기계적으로 판정할 검사는 hook에 둔다.
- 샌드박스 밖 명령의 허용·질문·차단만 Codex `.rules`에 둔다.

## 작성

- 행동 규정은 검증 가능한 완료 상태와 판정 기준을 중심으로 쓴다.
- 새 기준이 막을 구체적 오판과 기존 규율이 그 오판을 못 막는 이유가 없으면 추가하지 않는다.
- 사건의 표면형이 아니라 원인에 기준을 건다. 원인 밖의 정당한 사례까지 잡으면 범위를 좁힌다.
- 같은 소비자에게 같은 시점에 로드되는 중복 기준은 삭제하거나 병합한다.
- skill description에는 발동 조건을, 본문에는 절차와 중단·완료 조건을 둔다.
- 공통 철학과 플랫폼 실행 형식을 구분한다. `shared/principles.md`는 의미의 대조 기준이며 런타임 로드를 전제하지 않는다.
- 영구 문서에는 독자가 사용·변경·복구를 판단할 때 반복적으로 필요한 내용만 쓴다. 일회성 이전·사고·제거 내역과 그 과정의 내부 부산물은 반복 운영 기준으로 일반화할 때만 남기고, 사건 기록 자체는 넣지 않는다.

## 검증

원 사건이 있었다면 새 기준이 사건과 같은 원인의 다른 표면형을 막는지, 원인 밖의 정당한 사례를 잡지 않는지 확인한다. 관련 workflow 전체에서 책임 중복, 실행 불가능한 게이트, 제품 표면과 맞지 않는 경로를 함께 검사한다.
