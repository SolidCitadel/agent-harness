# 수행 진단 위임

주 에이전트가 수행하는 절차다. 이 skill이 생성한 진단 agent는 `~/.codex/self-diagnosis.md`를 따른다.

1. 부모 대화 이력을 상속하는 하위 agent를 생성한다. 지시에는 하위 agent가 진단 agent라는 것, `~/.codex/self-diagnosis.md`를 읽고 따르라는 내용, 어긋남이 드러난 사용자 발화·지점을 적는다. 진단 agent가 검수자를 직접 호출하려면 `~/.codex/config.toml`의 `[agents] max_depth`가 2 이상이어야 한다.
2. 진단 agent가 검수 입력을 반환하면, 부모 이력을 상속하지 않는 새 `harness_reviewer`에 그 입력을 전달하고 검수 보고를 진단 agent에 돌려준다.
3. 현재 작업의 교정은 주 에이전트가 맡는다. 반환된 보정 제안은 주 에이전트가 판단해 반영하고, 승인된 방향·범위를 바꾸는 보정은 사용자 승인 후 반영한다.
4. 재발 방지 개정안은 사용자 승인 전에는 현재 작업의 기준으로 삼지 않는다. `~/.codex/self-diagnosis.md`의 반환 항목 중 현재 작업 보정 제안을 뺀 나머지를 사용자에게 제시해 승인받는다.
5. 승인되면 승인된 최종안과 승인 과정의 변경을 같은 진단 agent에 전달해 적용을 지시한다. 지시할 수 없으면 주 에이전트가 `~/.codex/self-diagnosis.md`의 승인 후 적용 절차를 따른다.
