# memory 작성 (휴면)

memory는 description 매칭으로 회상되므로, meta-doc.md의 "없으면 새 세션이 뭘 잘못하나" 대신 각 항목에 **"미래 어떤 상황에서 회상되어 그때 어떤 다른 행동을 유도하는가"**를 묻는다. 답이 과거 사건 서술뿐이면 로그다.

- 시점 서사("오늘/이번에 X를 했다·고쳤다")를 영속 사실로 위장하지 않는다. 사건이 아니라 거기서 얻은 영속 규칙만 남긴다.
- 비자명한 적용 지침(어떻게 적용하는가)을 쓸 수 없으면 회상돼도 행동을 못 바꾸므로 로그다.
